# Jai Pari Mata Medical Store Website

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and footer year
- `images/` — 5 uploaded pharmacy photos

## Run in VS Code
1. Open this folder in VS Code.
2. Install the "Live Server" extension if you want a local preview.
3. Right-click `index.html`.
4. Choose "Open with Live Server".

You can also double-click `index.html` to open it in a browser.
